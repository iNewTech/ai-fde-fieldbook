## The recommended loop

1. Read the current lesson and understand the example.
2. Attempt the Q&A before opening the hidden answers.
3. Watch one primary video or course section for the topic.
4. Attempt the mini-project before opening its collapsed helper.
5. Implement from the skeleton, test failure cases and record evidence.
6. Paste the mentor skill into your AI provider and submit your work for review.
7. Pass the multiple-choice assessment at 100%, then pass the mentor's conceptual, practical and system-design checks.
8. Add the capability to the evolving portfolio system before starting the next topic.

## Video and courses

The [video and reading library](/references/) has one focused route for each major skill. Use the lesson's own link first; do not collect courses without building. Course access, account requirements and pricing can change, so use the linked official page to confirm availability.

## Papers and technical references

Use the [original papers and implementation references](/references/) after the lesson gives you the intuition. For every paper, write down its problem, mechanism, assumptions, experiment and limitation. For every framework or provider, read the current official documentation before using it in a deployment.

## Public versus private

This page and the repository contain synthetic examples and reusable learning material. Keep your answers, grades, API keys, employer data and customer data private. The collapsed answers and browser score help with study flow but are not security controls; the AI mentor's review is the authoritative gate.

## Improve the shelf

Links and software change. When a course or documentation link moves, open an issue or submit a small pull request with the replacement and its reason. Keep one primary resource per topic and do not add a link merely because it is popular.
