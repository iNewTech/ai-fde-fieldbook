# P5 submission contract

Follow the P5 brief in `docs/projects/index.md`.

Submit a data-flow diagram, requirements-to-control matrix, risk register,
20-case attack report, mitigation retests, role/deletion drill, cloud deployment
record, adaptation comparison, performance report and rollback evidence.

Each risk needs an asset, failure, impact, evidence, control, owner and residual
risk decision. Use only your own synthetic application for attacks. Do not
claim certification or legal compliance. Every unresolved practical gate remains
visible in the private progress record.
