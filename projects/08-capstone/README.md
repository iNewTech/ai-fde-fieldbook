# P8 evidence bundle

Follow the P8 brief in `docs/projects/index.md` and the system design track.

Required: charter, architecture decisions, source and API contracts, threat model,
version manifest, 50-case end-to-end evaluation, load report, deployment and
rollback record, operator runbook, user handover, executive demo and defense.

Reuse earlier project components. Implement the integration yourself. Each
published metric must identify the dataset, workload, method and whether it is
synthetic, estimated or measured in an authorized real pilot. Do not publish
personal grades, employer data, secrets or claims of unperformed tests.
